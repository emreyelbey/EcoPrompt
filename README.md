# EkoToken

TÜBİTAK 2204-A Lise Araştırma Projesi — yapay zeka kullanımının çevresel ayak izini (enerji, su, CO₂) ölçen web uygulaması.

## Kurulum

```bash
npm install
cp .env.example .env.local   # değerleri doldurun
```

## Komutlar

- `npm run dev` — yerel geliştirme (http://localhost:5173)
- `npm test` — testleri çalıştırır
- `npm run build` — üretim derlemesi (`dist/`)

Ayrıntılı gereksinimler: `docs/sartname.md`. Proje kuralları: `CLAUDE.md`.
